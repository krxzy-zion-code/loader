# Loader

Roblox service/controller lifecycle loader. This package depends on `krxzy-zion-code/logger` and expects Wally packages to be installed under `ReplicatedStorage.Packages`.

Wally package: `krxzy-zion-code/loader`

## Install

Add this to your project's `wally.toml` under `[dependencies]`:

```toml
Loader = "krxzy-zion-code/loader@^0.1.1"
```

Then run:

```powershell
wally install
```

## Publish

Publish `krxzy-zion-code/logger@0.1.1` first, then run `wally publish` from this directory.
