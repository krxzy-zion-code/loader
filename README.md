# Loader

Roblox service/controller lifecycle loader. This package depends on `krxzy-zion-code/logger` and expects Wally packages to be installed under `ReplicatedStorage.Packages`.

Wally package: `krxzy-zion-code/loader`

## Publish

Publish `krxzy-zion-code/logger` first, then run `wally publish` from this directory.
